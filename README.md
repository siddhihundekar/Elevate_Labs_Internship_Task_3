# Library Management System

**Elevate Labs Internship – Task 3**

This Java program is a multi-class **Library Management System** developed for **Elevate Labs Java Developer Internship (Task 3)**. 
It is a simple console-based application that helps manage books and users using core **Object-Oriented Programming** concepts in Java.

---

## 🎯 Objective

To build a **Java-based Command Line Interface (CLI)** Library System that manages books and users.
The user can perform operations like adding books, registering users, issuing books, returning them, and viewing book details.

---

## 🚀 Features

* Add new book details
* Register a new user
* Issue a book by its ID
* Return an already issued book
* View all available + issued books
* Smooth menu-driven interface
* Runs perfectly on Eclipse, VS Code, IntelliJ, or any terminal

---

## 🧠 Key Java Concepts Used

* **Object-Oriented Programming (Classes & Objects)**
* **Encapsulation** using private fields
* **Collections Framework (ArrayList)** for storing books & users
* **Method-based operations** for issue/return flow
* **Scanner Class** for reading user inputs
* **Control Statements** (loops, switch cases, conditionals)

---

## 🛠️ Tools & Technologies

* **Java (JDK 21)**
* **Eclipse IDE**
* **Terminal / Console** for execution

---

## ▶️ How to Run

1. Open the project in **Eclipse**.
2. Create the files:
   * `Book.java`
   * `User.java`
   * `Library.java`
   * `Main.java`
3. Compile the entire project.
4. Run the main file: **Main.java**.
5. Use the menu to add books, register users, issue/return books, etc.
